# Case 02: an answer reframes the problem

## Input
H: I want a dashboard to track my freelance invoices.
PM: What goes wrong today that makes you want it, and who else sees these invoices?
H: Only me. Honestly the invoices are fine. What I lose track of is which clients still owe me for work I haven't invoiced yet.

## Pass
- One sentence saying what the PM now understands: the real problem is un-invoiced work, not the invoices.
- Then one or two new questions that follow from that.

## Fail
- Carries on as if the dashboard were the problem.
